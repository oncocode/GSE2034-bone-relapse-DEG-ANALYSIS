# GSE2034 Bone-Relapse DEG Analysis

Differential gene-expression analysis of breast-cancer samples with and without bone relapse.

## Dataset
- GEO accession: GSE2034
- Platform: GPL96, Affymetrix HG-U133A
- Comparison: bone relapse vs no bone relapse

## Methods
GEOquery, limma, hgu133a.db, clusterProfiler.

## Outputs
Volcano plot, heatmap, PCA, DEG tables, GO and KEGG enrichment.
